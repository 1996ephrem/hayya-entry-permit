====================================================================
  FIREBASE SETUP GUIDE - Cloud Database Integration
====================================================================

STEP 1: Create Firebase Project
--------------------------------
1. Go to: https://console.firebase.google.com
2. Click "Add project"
3. Project name: hayya-entry-permit (or any name)
4. Click "Continue"
5. Disable Google Analytics (not needed) or enable it
6. Click "Create project"
7. Wait for setup to complete
8. Click "Continue"


STEP 2: Enable Realtime Database
---------------------------------
1. In Firebase Console, click "Realtime Database" in left menu
2. Click "Create Database"
3. Choose location: (choose closest to Qatar, like Europe or Asia)
4. Start in "Test mode" (we'll secure it later)
5. Click "Enable"


STEP 3: Get Firebase Configuration
-----------------------------------
1. Click the gear icon (⚙️) next to "Project Overview"
2. Click "Project settings"
3. Scroll down to "Your apps"
4. Click the web icon (</>) to add a web app
5. App nickname: Hayya Entry Permit
6. Click "Register app"
7. COPY the firebaseConfig object (you'll need this!)
8. Click "Continue to console"


STEP 4: Set Database Rules (Security)
--------------------------------------
1. Go to "Realtime Database" in left menu
2. Click "Rules" tab
3. Replace the rules with this:

{
  "rules": {
    "permits": {
      ".read": true,
      ".write": "auth != null || true"
    }
  }
}

4. Click "Publish"

NOTE: This allows public read/write. For production, you should add 
authentication. But for now, this works.


STEP 5: Update firebase-config.js
----------------------------------
1. Open the file: firebase-config.js
2. Replace the firebaseConfig object with YOUR config from Step 3
3. It should look like:

const firebaseConfig = {
  apiKey: "AIzaSyXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX",
  authDomain: "hayya-entry-permit.firebaseapp.com",
  projectId: "hayya-entry-permit",
  storageBucket: "hayya-entry-permit.appspot.com",
  messagingSenderId: "123456789012",
  appId: "1:123456789012:web:abcdefghijklmnop",
  databaseURL: "https://hayya-entry-permit-default-rtdb.firebaseio.com"
};

4. Save the file


STEP 6: Test Locally
---------------------
1. Open login.html in your browser
2. Create a test permit
3. Open the SAME website on your phone
4. The permit should be visible!


STEP 7: Deploy to GitHub
-------------------------
Run these commands in Command Prompt:

cd D:\telegram\visaproject
git add .
git commit -m "Add Firebase cloud database integration"
git push


STEP 8: Wait & Test
-------------------
Wait 2-3 minutes for GitHub Pages to update, then:
1. Create a permit on your PC
2. Scan QR code with your phone
3. You should see the full permit details!


====================================================================
  TROUBLESHOOTING
====================================================================

Problem: "Firebase is not defined"
Solution: Make sure firebase-config.js is loaded in HTML files

Problem: "Permission denied"
Solution: Check database rules in Firebase Console

Problem: Data not showing
Solution: Open browser console (F12) and check for errors

Problem: "Firebase initialization error"
Solution: Double-check your firebaseConfig credentials
